# Homedeco Shop

## 프로젝트 소개
Homedeco Shop은 PHP와 MySQL을 사용하여 구현한 개인 웹 프로젝트입니다.  
상품 정보를 관리하는 웹 서비스 구조를 중심으로,  
백엔드 서버와 데이터베이스 연동 및 CRUD 기능 구현을 목표로 개발했습니다.

회계·전산 업무 경험을 바탕으로,  
관리자 관점에서 필요한 데이터 흐름과 관리 기능을 고려하여 설계했습니다.

---

## 주요 기능
- 상품 목록 조회
- 상품 상세 페이지
- 상품 등록 / 수정 / 삭제 (CRUD)
- PHP–MySQL 데이터베이스 연동
- 기본적인 웹 서비스 구조 구현

---

## 기술 스택
- **Backend**: PHP  
- **Database**: MySQL  
- **Frontend**: HTML, CSS, JavaScript  
- **Server**: Apache  
- **Tools**: VS Code, Git, phpMyAdmin

---







---

## 구현 및 학습 포인트
- PHP를 활용한 서버 사이드 로직 구현
- MySQL과 연동한 데이터 처리 흐름 이해
- CRUD 기능을 통한 데이터 관리 구조 학습
- 웹 서비스의 기본적인 백엔드 구조 이해
- 관리자 페이지 관점에서의 데이터 관리 방식 경험

---

## 실행 방법
1. Apache 기반 로컬 서버 환경에서 프로젝트 실행
2. MySQL 데이터베이스 생성
3. DB 테이블 생성 후 `/config` 내 설정 파일에 DB 정보 입력
4. 브라우저에서 프로젝트 접속

---

## 프로젝트 목적
이 프로젝트는 PHP 백엔드 개발자로서  
웹 서비스의 기본 구조와 데이터 처리 흐름을 이해하기 위해 진행한 개인 프로젝트입니다.  
실제 서비스와 유사한 구조를 경험하며 서버 개발 역량을 강화하는 것을 목표로 했습니다.
